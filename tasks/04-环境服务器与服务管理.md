# 任务 04：环境服务器与服务管理

## 目标

管理环境、服务器及 MySQL/Redis/Nginx 服务，并保留未分类/待归属占位结构。

## 前置依赖

依赖[任务 02](02-本地数据模型与持久化.md)和[任务 03](03-项目级资源管理.md)；为任务 06、07、09 提供归属目标。

## 工作项

- 编辑环境、服务器名称、服务端 IP、端口及服务；防火墙来源 IP 必须为独立字段。
- 仅允许首版三种服务类型；支持服务字段和凭据。
- 为每个项目保证可选择“未分类环境”和“待归属服务器”，用于不完整解析结果，不能伪造正式归属。

## 测试与验证

单元测试树约束、三类服务、服务端/来源 IP 不混淆和占位归属；人工检查完整路径。待工具链就绪后人工执行 `xcodebuild test -scheme 工程资料工具 -enableCodeCoverage YES`；当前未运行。

## 完成标准

树结构及占位符合[计划 02](../plan/02-用户流程与信息架构.md)。前序任务 02、03；后续任务 05、06、07、09。
