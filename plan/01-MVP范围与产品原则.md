# MVP 范围与产品原则

## 目标与边界

本 MVP 是 macOS 个人工程资料工具：在十几个项目的规模下，快速录入、查看和逐字段复制工程连接资料。应用原生常驻顶部菜单栏并支持登录启动；菜单栏负责高频录入、查看和复制，独立管理窗口负责低频编辑、历史与备份。

完全本地存储、完全由可解释的规则解析。不使用云端模型、本地模型、云同步、自动剪贴板监听或复杂全文检索。用户主动复制消息后，须主动点击菜单栏并选择“粘贴”才读取剪贴板内容。

## 已确认的产品原则

- 不得静默覆盖：所有解析结果均展示完整归属路径与字段差异，经用户确认后才保存。
- 不凭空编造事实：规则只能从原文提取或按明确规则归类；缺环境进入“未分类环境”，缺服务器进入“待归属服务器”。
- 本地资料可见：密码不遮罩，不启用 Touch ID 或系统密码验证；这会带来旁观、截屏、恶意本机软件读取等泄露风险，用户须仅在受信任设备和环境使用。
- 不在日志、测试夹具或文档示例中写真实凭据。示例统一使用 `demo-user`、`示例口令-请替换`、`203.0.113.10` 等虚构或保留地址。
- 旧工程文档不批量导入；未来每次实际使用时人工复制一次。无迁移，直接替换。

## 范围内与范围外

范围内：项目资料树、项目级 VPN 与系统入口、环境/服务器/服务、MySQL/Redis/Nginx、任意可登录资源的多组凭据、自定义字段、纯规则粘贴解析、差异确认、历史版本、菜单栏复制、备份恢复、登录启动。

范围外：账户体系、联网、云端或本地 AI、自动监听剪贴板、加密、权限验证、全文索引、旧资料批量导入、自动合并恢复、CI/CD。
