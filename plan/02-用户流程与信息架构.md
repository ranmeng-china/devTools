# 用户流程与信息架构

## 数据树与资源卡片

数据树固定为：**项目**直接包含项目级 VPN、项目级系统入口；项目还包含**环境**，环境包含**服务器**，服务器包含**服务**。首版服务类型仅 MySQL、Redis、Nginx。所有可登录资源（VPN、系统入口、服务器服务等）统一支持多组凭据和自定义字段。

资源卡片以“资源名称 + 字段信息”展示；每个字段各有独立复制操作。卡片支持多凭据，按最近使用排序；轻量过滤仅匹配项目名称与服务器名称/IP，不做全文检索。

## 日常录入

1. 用户复制一段资料消息。
2. 用户点击菜单栏应用，选择项目与“粘贴录入”。
3. 应用按本地规则解析原文，并根据文本匹配资源归属。
4. 如候选服务器不止一个，用户必须选择；如信息不完整，显示“未分类环境”或“待归属服务器”。
5. 界面展示完整路径、原文、字段差异及规则解释。
6. 用户确认后以原子 ChangeSet 保存；取消则不改动数据。

## 菜单栏与管理窗口

菜单栏：项目切换、最近资源、轻量过滤、主动粘贴录入、逐字段复制、打开管理窗口。管理窗口：完整树编辑、资源与凭据管理、自定义字段、历史变更、待整理资料、备份导入导出、登录启动设置。

## 交互约束

密码显示为明文且允许独立复制；界面应明确提示泄露风险，但不额外添加认证或遮罩机制。所有歧义均进入人工确认；服务端 IP 与防火墙来源 IP 分字段展示，绝不互相替代。
