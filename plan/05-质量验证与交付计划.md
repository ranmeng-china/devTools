# 质量验证与交付计划

## 人工质量门槛

禁止 CI/CD；构建、静态分析、测试、发布全部人工操作。工具链安装并锁定版本后，人工执行构建、静态分析和测试，三者均须退出码为 0、零报错。项目总体测试覆盖率必须不低于 90%，并覆盖关键路径与异常分支；低于 90% 时必须记录差距并补测，任务保持未完成且禁止发布。

当前 macOS 为 15.7.9，未安装/配置 Xcode 与 Swift 命令行工具，所以本计划不能声称任何构建或测试已通过。待人工确认并锁定工具链版本后，按工程实际 scheme 替换命令模板：

```sh
xcodebuild -scheme 工程资料工具 -configuration Debug build
xcodebuild -scheme 工程资料工具 -configuration Debug analyze
xcodebuild test -scheme 工程资料工具 -enableCodeCoverage YES
```

上述命令模板当前未运行。

## 验收场景

人工验收须覆盖：主动粘贴录入与取消无写入；单一/多个/缺失归属；字段差异和解释；多凭据与三版裁剪；多字段更新频率不一致时的独立裁剪；恢复产生新变更；敏感值保真；字段级来源片段不含其他字段值且随版本同事务删除；待整理原文的替换、转正与删除；备份往返后旧敏感值不可恢复；服务端与来源 IP 区分；卡片逐字段复制；最近使用与轻量过滤；未分类与待归属人工校正；备份校验、预览、显式整库替换；登录启动；无网络、无模型、无自动监听行为。

## 交付与迁移

发布前人工检查文档、隐私提示和脱敏示例；仅在人工构建、静态分析、测试、手工冒烟验证均通过且项目总体覆盖率不低于 90% 后发布。旧工程文档不导入；无迁移，直接替换。
